# Database updates

If your database is already set up, run only the new update files, in number
order, in Supabase → SQL Editor → New query (paste one file, press Run, then
the next). Each file is safe to run more than once.

If you are setting up a brand-new database, run `supabase/schema.sql` instead:
it already contains everything below.

| Files | What they add |
| --- | --- |
| 10 to 14 | Request Inbox & Landlord Maintenance Plan: request page, inbox, houses, tenants, landlords, plans and hour bank, approvals, house profiles, guides, alerts |
